# Znawca

Znawca is a Windows-first, fully offline multimedia learning and testing application.

Development and acceptance are governed by `Znawca 需求规格说明书 V1.0.docx`.

## Repository policy

- The V1.0 specification is the single source of truth.
- Large source media stays outside Git.
- Automated tests use small generated fixtures and mock media.
- Feature branches use the `codex/` prefix.
