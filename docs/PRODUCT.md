# ZNAWCA 当前产品基线

> 整理日期：2026-10-15。描述应有行为，不等同于已实现或已验收；差距和验证见 [WORK.md](WORK.md)。团队约束统一见 [AGENTS.md](../AGENTS.md)。

## 1. 定位与范围

Windows 64 位本地学习与测试应用：用户提供结构化 Excel 和媒体，系统生成题目，保存本地进度、成绩和困难记录。核心功能离线运行，无登录、许可证、服务器、云或 AI 依赖，不上传课程和记录。

提供安装版与便携版；安装、快捷方式、卸载和覆盖升级属于交付要求。支持课程发现、导入校验、Learning、Testing、历史回放、多语言界面与媒体播放。

当前不纳入：Web、账户、支付、云同步、教师后台、社交、其他操作系统、AI 出题/语义判分/纠错/媒体识别、完整 Excel 编辑器、复杂逐文件关联编辑器、属性间横向出题、反向多选、自动同义词、难度等级列或固定递进题序。其他产品的功能不进入本项目。

## 2. 课程数据与导入

### 发现与加载

- 可直接选择单门课程或课程库；课程库一级子目录中含顶层 .xlsx 的目录为候选。普通文件、无工作簿的子目录及 Excel 锁文件 `~$*.xlsx` 不作课程。
- 默认读取第一个工作表。空行忽略，必要的名称和列标题不得空缺或重复；内容按 Unicode 显示，不翻译，不修改用户源 Excel。
- 启动及刷新只发现目录、工作簿和语言后缀；打开或恢复课程时才读取该课程正文与媒体。并发点击同一课程应合并加载。
- 课程与媒体使用真实路径确认范围，链接不能跳出允许目录；媒体格式校验只读所需文件头。
- 自动整理课程采用副本，保留源文件；正常导入无需用户复制课程。

### V2 格式

同一课程目录可放 `Birds_Eng.xlsx`、`Birds_Ru.xlsx` 等同基础名、不同语言后缀的工作簿；内容媒体统一放 `media/`，朗读放 `speech/<语言后缀>/`。课程身份与内容语言共同隔离进度、会话、历史和困难记录。界面语言切换不改变课程语言。

| 位置 | 含义 |
|---|---|
| A1 | 当前语言课程显示名 |
| A2+ | 该行事物主媒体引用，可代替名称作为提问线索 |
| B1 | 名称与主媒体的双向题干 |
| B2+ | 名称及显式别名 |
| C1+ | 属性题干或筛选列标题 |
| C2+ | 文本答案或表达该属性的媒体引用 |

- B1 和可双向出题的属性标题用首个 `/` 分隔正反题干，两侧必填；缺失时阻断导入并定位标题单元格。普通属性正向为名称→单元格，反向为单元格→名称。
- `#` 前缀为仅筛选列；`$` 为仅作问题（允许反向），`*` 为仅作答案（允许正向）。角色标记补充方向限制，不替代歧义检查。
- 单元格只写 media 中的文件名；`/` 分隔多个同类别变体，如 `flag-front.png/flag-waving.jpg`。不允许目录路径或越界引用。
- A 列和每个普通属性列各自保持非空单元格类别一致：文字、图片、音频、视频四者之一。同格或同列混合类别应精确报错。
- 同格媒体变体代表同一答案，随机轮换并减少短期重复，不能互作干扰项。属性媒体只表达该单元格，不与整行其他媒体混用。
- 图片支持 JPG/JPEG/PNG/WEBP/BMP/GIF，音频 MP3/WAV/M4A，视频 MP4；扩展名及签名应匹配。

### 兼容与错误

V1 名称在 A 列、名称目录关联整行媒体的课程只读兼容；旧式按名称与编号平铺的媒体兼容不等于 V2 规范。V1/V2 应有明确识别契约，不能静默改变旧格式含义；显式标识位置尚未形成一致文档，实现差距见 WORK.md。

结构错误（损坏工作簿、空表、名称/标题错误、混合类别、非法双向标题等）阻断课程。受支持扩展名的单元格内容按媒体引用校验；缺失或损坏媒体产生可定位警告并跳过该媒体/关系，不能退回成文件名答案；其余有效关系继续，全部失效才阻断。可选朗读、提示音缺失可静默跳过。

错误信息包含适用的文件、工作表、行列/单元格或媒体路径、原因与修复建议。V1 合并名称单元格续行应归入对应对象，不误报空名称。

## 3. 出题、范围与答案

- 以名称为中心，支持文字、图片、音频、视频的名称↔对应单元格题；A 列主媒体可作事物线索。纯文字课程也可双向学习。不生成国旗↔国歌等属性间题目。
- 反向答案不唯一时跳过；不推断课程之外的现实知识。
- 题型可单选或混合。`#` 同字段多值 OR、不同字段 AND；多值筛选按分号拆分。筛选后所有有效答案相同的属性列跳过；显示有效对象/关系数、可用题型及禁用原因。
- 范围为筛选结果加全面覆盖或抽取数量，不增加手选行区间。原批准要求默认全面覆盖，抽取量从 3 到有效最大量，不足 3 时允许实际数量；当前默认值差异见 WORK.md。
- 严格模式只从筛选范围取干扰项，宽松从当前整门课取，题目对象仍来自筛选范围；不跨课程。
- 排除正确对象、等价答案、显式别名和同格媒体变体后取 4 个选项，不足用 3 个。仍不足时文字题转输入；媒体题转显示媒体→输入名称，不要求输入文件名。
- Excel 中 `;` 分必答组、`/` 分组内任选别名。`China/PRC; Asia` 接受 `China; Asia`、`PRC; Asia`、`China; PRC; Asia`；选择项按声明显示别名。
- 答题端接受 `;；,，`，顺序无关；忽略大小写、首尾空格，压缩连续空格。`/` 不是普通答题分隔符；不推断未声明同义词。
- 仅把下标数字 ₀—₉ 与 0—9 等价；不使用 NFKC 或通用上标归一。`H₂O` 等价 `H2O`，`x²` 不等价 `x2`。
- 完全正确必须命中所有必答组且无额外错误答案。Learning 可显示部分命中但仍重做；Testing 完全正确计 1，其余计 0；困难记录按同一口径判断。

## 4. 会话、进度、困难与保存

### Learning

随机抽题并尽量先覆盖不同对象，避免属性或题型多的对象天然更常出现。首次完全正确即移出活动池；答错或部分正确后回池，此后连续两次完全正确才移除，中途出错归零。回池后与剩余题重新打乱，有其他题时避免固定紧接同一错题。退出保存；恢复保持保存队列，不额外重排，允许重新开始。

### Testing

从筛选与启用题型下全部有效关系抽题，不要求已掌握；每个入选关系一次测试只出现一次。计时关闭或每题 10/15/20 秒；超时按错误处理，原批准要求进入下一题，当前实现仍待复核。结束展示百分比、完全正确数、错误数、总数，按课程保存日期、范围和计时信息。

### 进度与困难

- 一个名称＋有效学习单元格关系为一个进度单位：A-B 主媒体识别算一个，B 与每个有效属性单元格各算一个。正反向、题型、媒体变体不重复计数；空单元格、失效媒体、筛选列及无区分度列不计。
- Learning 开始固定总数，达到移除条件才算掌握，显示已掌握/剩余及对应进度条；不显示会因重试膨胀的 Question X of Y。Testing 显示总数/已完成/剩余。
- 困难按课程（含内容语言）＋对象行记录。完成会话内任一错误或部分正确则标困难、恢复计数归零；同会话重试只形成一次对象级结论。
- 困难优先开启时权重固定 2:1，关闭等权；不采用 30%/40%配额，不按错误次数增加权重。
- 后续两个实际出现且该对象自身无错的完成会话后移除；未出现不计数，其他对象错误不影响它。支持单条删除和按课程清空。

### 本地记录

保存课程根目录、最近课程、界面语言、会话设置、未完成学习及连续正确次数、困难状态、媒体历史、学习/测试历史与播放器设置。历史支持只读原题回放、作答与判定对照；不把重新生成题目伪装成原题重放。

学习进度、困难、测试历史及全部本地数据提供相应清除入口和确认。数据属于当前 Windows 用户，不能写入课程源文件。旧存档迁移是有效功能，不按旧工程副本删除。

本地读写失败时显示明确提示与重试入口，保留当前内存中的操作结果；保存按顺序执行，不能用较早的快照覆盖后续修改。

## 5. 媒体交互与界面

- 内容媒体本身是题目/答案；文字朗读是另一用途。朗读位于 `speech/<lang>/`，普通单元格 `C4.mp3`，双向标题 `C1-F.mp3`/`C1-R.mp3`。各语言行列对应，坐标变化时同步重命名录音。
- 新文字题按界面顺序播放已有文字片段，题目本身是媒体时不自动朗读；题干和文字答案提供手动扬声器，点击播放不提交答案。没有录音时跳过，不启用 TTS。
- 课程根目录 `correct NN.mp3`、`incorrect NN.mp3`，NN 为 00—99，可不连续；提交后随机选对应集合，尽量不连续重复。
- 串行播放正误提示音→正确答案音频。文字答案用坐标朗读，音频答案用内容音频，图片/视频无独立答案音频则跳过。切题、退出、再次播放或手动媒体打断旧链；手动媒体之间也互斥。损坏或缺失音频不阻断判题、保存和下一题。
- 音频提供播放、暂停、重播和音量；视频提供播放、暂停、进度、音量和放大。异常媒体不能导致应用崩溃。
- 四个图片/音频/视频选项固定 2×2，三个按两行；支持的 960×640 常规最小窗口内同时可见。高窗口适当放大，宽屏会话占满内容区；极端内容保留选项区内部滚动兜底，操作栏不遮挡答案。
- 保持深绿、金色和金属按钮风格；状态不只依赖颜色。界面语言英/波/简中/阿/俄独立于课程内容，阿拉伯语 RTL；固定文案从语言资源读取。
- 最新确认（2026-10-03）：文字题答错不显示关联图片合集；媒体题只显示题目或答案自身媒体。该规则取代旧“答错显示关联小图”任务。
- 最新确认（2026-10-05/06）：窗口按主屏工作区约 75%×80% 创建且不低于 960×640；适配 1080p 大屏，1280×720 下题干、选项、反馈与操作不互相遮挡。尺寸细节属于实现，验收目标优先。
- 保留已确认交互：无冗余侧栏、离线标识和重复隐私横幅；课程/历史/困难列表标题固定、内容滚动；设置分组按内容展开；历史使用独立回放视图。
- Windows 图标透明背景、多尺寸 ICO（16/24/32/48/64/128/256），保持深色金色品牌辨识。
