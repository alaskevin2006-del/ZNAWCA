# 待用户确认：属性交叉关联

## 现状

ZNAWCA 目前以事物名称为关联中心，仅生成“事物 ↔ 属性/媒体”题目。

示例：国家可分别关联国旗和国歌；系统可考察“国家 ↔ 国旗”“国家 ↔ 国歌”，不能直接考察“国旗 ↔ 国歌”。

## 潜在问题

用户可能需要属性或媒体之间的横向关联题，例如“看到国旗，选择对应国歌”。现有模型无法生成此类题目。

## 向用户确认

是否需要支持同一事物下任意属性/媒体之间的双向出题？

## 可选优化

新增“属性/媒体 A → 属性/媒体 B”出题能力，并允许课程设计者指定哪些列可以作为题目或答案。
