# ZNAWCA 14 项修改决策基线

> 状态：已批准实施｜只有项目主控可以修改本文件

## 1. 已批准决策

| ID | 问题 | 固定方案 | 明确边界 |
|---|---|---|---|
| D-01 | 属性值可能对应多个事物，反向单选会出现多个正确答案。 | 反向关系在当前候选数据中不唯一时跳过；正向题不受影响。 | 不生成反向多选，不推断课程外知识。 |
| D-02 | 答题者可能使用不同中英文分隔符。 | Excel 仍只用半角分号 `;`；答题输入兼容 `;`、`；`、`,`、`，`。 | 不把 `/`、`\`、冒号等符号当分隔符。 |
| D-03 | 多部分答案可能顺序不同。 | 将答案按集合比较，顺序无关。 | 缺答、多答或错答均不算完全正确。 |
| D-04 | 常见大小写与空格差异可能误判。 | 大小写不敏感；忽略首尾空格；连续空白压缩为一个空格。 | 不做拼写纠错、语义相似或自动同义词。 |
| D-05 | 化学式下标数字不便直接键入。 | 判题时将 `₀—₉` 与 `0—9` 对应归一后比较。 | 不等同上标；不启用通用 NFKC；其他字符仍精确比较。 |
| D-06 | Learning、Testing 和困难记录可能使用不同正确口径。 | 只有全部必答项命中且无额外答案才是完全正确；部分正确、漏答、多答、错答、超时均为未完全正确。 | Learning 可展示部分命中，但仍重做；Testing 计 0；困难判定记为错误。 |
| D-07 | 范围和筛选容易被扩展成手选 Excel 行。 | 同一 `#` 字段多值为 OR，不同字段间为 AND；范围是筛选结果＋全面覆盖或抽取数量。 | 不增加手选行、行区间或对象编辑器。 |
| D-08 | 严格/宽松与困难优先混淆。 | 严格仅从当前筛选范围抽干扰项；宽松可从当前整门课程抽干扰项；题目对象始终来自筛选范围。 | 不跨课程取干扰项；不改变困难抽样权重。 |
| D-09 | Testing 当前只取已掌握关系。 | 从当前筛选、启用题型和题量下的全部有效关系抽题，不要求已掌握；每个入选知识项目在本次测试只出现一次。 | 不改变测试计分与计时规则。 |
| D-10 | 困难记录单位、抽样和退出逻辑偏离规格。 | 按“课程＋对象行”记录；开启困难优先时困难对象权重 2、普通对象权重 1，关闭时相同；对象在两个实际出现且自身无错的完成会话后退出，期间该对象任一错误归零。 | 删除 30%/40%配额；其他对象出错不影响该对象；错误次数不累加权重。 |
| D-11 | 四个图片或音频选项需要滚动。 | 四个图片或音频选项在受支持的常规窗口内固定 2×2、同时可见、无需题目区域滚动；三个选项按两行布局。 | 本轮不规定视频 2×2，不重做整体视觉风格。 |
| D-12 | 课程正误提示音单一。 | 扫描课程根目录中严格匹配 `correct NN.mp3`、`incorrect NN.mp3` 的文件；`NN` 为 `00—99` 且可不连续；完全正确播放 correct 集合，其他结果播放 incorrect 集合；随机且尽量不连续重复。 | 不把相似文件名、对象音频或朗读音频纳入集合；集合为空不阻断答题。 |
| D-13 | 自动音频可能重叠或顺序混乱。 | 提交后按“正误提示音→正确答案对应音频”串行播放；切题、退出或新播放请求停止旧链；文件不存在时跳过。 | 本轮沿用 V1 Excel 坐标朗读方案，不实施单元格内容媒体重构；不得让音频播放等同于提交答案。 |
| D-14 | 导入和媒体错误可能不可定位或阻断无关内容。 | 错误/警告包含文件、工作表、行列或媒体路径、原因和修复建议；单个缺失、损坏或不支持媒体只跳过对应媒体/题型，其他内容继续；没有任何有效学习内容才阻断课程。 | 不把缺失媒体的文件名显示成题目或答案；不修改用户源 Excel。 |

## 2. 本轮明确排除

以下内容仍待客户确认，WorkBuddy 不得实现、预埋或顺手重构：

1. 媒体从“整行对象”重构为“具体单元格媒体”。
2. `A1/A2+/B1/B2+` 的 Excel V2 结构和中性 A 列。
3. 多语言工作簿、共享 `media/`、分语言 `speech/` 目录。
4. 单元格以 `/` 引用多个媒体变体。
5. `正向题干 / 反向题干` 的新表头解析。
6. `/` 显式别名解析。
7. 取消或新增特殊列角色标记。
8. “总数/已掌握/剩余”的新知识关系计数与界面。
9. 视频选项固定 2×2。
10. Web、账户、付费、后台、AI、Anvil 功能。
11. 客户尚未给出的五种界面翻译修订清单。

若某项批准任务必须依赖以上任一排除项才能完成，记录阻塞并返回主控，不得自行选择方案。
