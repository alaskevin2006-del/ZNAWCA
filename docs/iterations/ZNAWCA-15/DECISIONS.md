## 3. V2 实现决策（新增）

| ID | 问题 | 固定方案 | 明确边界 |
|---|---|---|---|
| D-15 | 中性 A 列与 V2 Excel 结构 | `A1`＝当前语言课程显示名，`A2+`＝该行主媒体引用；`B1`＝名称双向题干，`B2+`＝名称/别名；`C1+`＝属性双向题干，`C2+`＝文本答案或属性媒体引用。 | 不自动翻译课程内容；A 列媒体代替 B 列名称作为提问其他属性时的事物线索。 |
| D-16 | 多语言工作簿与共享媒体 | 同一课程目录放多语言工作簿 `Birds_Eng.xlsx`/`Birds_Ru.xlsx`；共享 `media/` 目录放内容媒体；文字朗读按 `speech/<lang>/` 分语言目录。按基础名＋语言后缀解析工作簿；按「课程 ID＋内容语言」隔离学习记录。 | 界面语言独立切换，不改变内容语言；英俄版本进度/困难/测试历史互不覆盖。 |
| D-17 | 媒体整行→单元格映射 | 媒体引用语法统一应用于 A 列和普通属性单元格；引用文件在 `media/` 中精确存在且格式受支持时识别为媒体，不显示文件名。A 列媒体为主表现，普通属性单元格媒体只表达该属性。 | 只生成「名称↔单元格」题，不生成属性间横向题（国旗↔国歌）。 |
| D-18 | 一个单元格多个媒体变体 | 单元格用 `/` 列出多个同类型媒体文件，如 `flag-front.png/flag-waving.jpg`；每次随机选一个，避免短期重复。不同选项图片可混用 JPG/PNG/WEBP。 | 每列非空单元格统一为文字/图片/音频/视频一种类别；同一单元格只允许一种媒体类别及其变体；`/` 只作变体分隔，文件名不得含路径。 |
| D-19 | 双向题干表头 | 列标题写 `正向题干 / 反向题干`，首个 `/` 分隔两方向，两侧均必填。 | 缺 `/` 或任一侧时拒绝导入并报文件/工作表/标题单元格位置；`/` 在标题中是保留字符。 |
| D-20 | 显式别名 | 先 `;` 分必答组，再 `/` 分组内任选别名；`China/PRC; Asia` 要求 `Asia`，接受 `China` 或 `PRC`；同时输入多个已声明别名也判对；选择题原样显示别名。 | 不自动推断同义词，不使用 AI。 |
| D-21 | 列角色标记（补充机制） | 作者可用稀有符号（`$`/`*`）在表头声明某列「仅作问题/仅作答案」；不替代 D-01 歧义反向题跳过逻辑，只在作者显式声明时生效。 | 列标记只约束出题方向，不改变数据本身；未声明的列不受影响。 |
| D-22 | 单元格文字朗读 | 朗读文件放当前工作簿语言的 `speech/<language>/`；普通单元格坐标命名 `C4.mp3`；双向标题 `C1-F.mp3`/`C1-R.mp3`；文字题出现时按界面显示顺序播放已有片段；题目本身是图片/音频/视频时不自动朗读；问题行和文字答案按钮提供手动扬声器按钮。 | 朗读音频与内容媒体是两套用途；没有朗读文件时静默跳过，不启用 TTS。 |
| D-23 | 新题自动播放文字音频 | 新文字题出现时播放与该问题单元格关联的音频，除非题目本身已是媒体。 | 播放不阻断判题、计分、保存和下一题。 |
| D-24 | 进度统计 | 一个「名称＋学习单元格」关系计一个进度单位；总数在 Learning 开始时固定；已掌握＝达到移除条件；剩余＝总数－已掌握；重试不增总数；Testing 显示总数/已完成/剩余。 | 空单元格、缺失/损坏媒体、无区分度被跳过的列不计；正反向、题型、媒体变体不重复计数。 |
| D-25 | 视频选项 2×2 | 视频选项与图片、音频一样固定 2×2 布局。 | 本轮不重做整体视觉风格。 |
| D-26 | Learning 进度展示 | Learning 顶部去掉「Question X of Y」，改显已掌握/未掌握（与 Testing 同款 unit-progress 计数）；进度条双段：已掌握段填充 + 未掌握段留空，答错重入队不推进。 | 学习者不需要知道自己被机器问了多少次；题目总数固定不无限扩张。 |

## 5. 兼容与约束

- V1 课程按「名称目录→整行媒体」只读兼容；V2 用单元格媒体＋多语言结构；格式版本可识别，不允许靠猜测切换，不改用户源 Excel。
- 所有导入错误给出文件路径、工作表、单元格、原因和修复示例；单媒体异常只跳过该媒体/关系，不阻断同课程其他有效内容；仅课程不再含任何有效学习关系才阻断。
