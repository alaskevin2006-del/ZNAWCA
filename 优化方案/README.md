## 记录规则

- 原始反馈不是实施指令；客户确认、Approved 规格或主控明确批准的结论才进入方案。
- 分析顺序：问题 → 需求 → 候选方案。
- 正式方案格式：场景 → 问题 → 规则 → 验收标准。
- 同一实施结论只在 `优化方案.md` 维护，其他文件只作索引或引用；如有冲突，以更新后的原始证据、Approved 规格和该方案中的状态标记为准。
