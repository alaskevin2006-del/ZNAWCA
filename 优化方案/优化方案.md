## 2. Excel、多语言与媒体

### 2.1 多语言课程共用媒体

- **问题：**当前媒体按本地化事物名称匹配；名称随语言变化时，需要复制或重命名媒体。当前加载器也只允许课程目录内存在一个工作簿。
- **方案：**同一课程的所有语言工作簿与媒体统一放在一个课程目录。工作簿使用语言后缀，例如 `Birds_Eng.xlsx`、`Birds_Ru.xlsx`。图片、自然声和无解说视频可由各语言工作簿共同引用；含语言的内容音频/视频由各语言工作簿分别引用对应文件。文字朗读音频按语言分目录，避免同名冲突。

```text
Birds/
├─ Birds_Eng.xlsx
├─ Birds_Ru.xlsx
├─ media/                 # 共享及语言专用的内容媒体，均由单元格精确引用
├─ speech/Eng/            # 英语文字朗读
├─ speech/Ru/             # 俄语文字朗读
├─ correct 00.mp3
└─ incorrect 00.mp3
```

- **规则：**文件夹名和工作簿语言后缀按明确规则解析：`Birds` 是课程 ID，`Eng`/`Ru` 是内容语言代码；不要求两个完整工作簿名同时等于文件夹名。所有内容媒体仍统一放在一个 `media/` 中：跨语言媒体直接共用同一文件，带语言的内容媒体使用语言后缀并由对应工作簿精确引用。课程入口先选择内容语言版本，界面语言仍独立切换；进度、未完成会话、测试历史和困难记录至少按“课程 ID＋内容语言”隔离，不能让英俄版本相互覆盖。
- **性质：**共享媒体是客户明确提出；上述目录、基础名匹配和分组方式为**主控已定**。
- **验收：**英语和俄语工作簿可引用同一张图片；含语言的内容媒体及文字朗读各自正确；切换界面语言不改变课程内容语言；两个内容语言版本的学习记录互不覆盖。

### 2.2 中性 A 列与第一行

- **问题：**客户要求新增中性 A 列并将原名称列移至 B 列；同时要求 `A1` 保存当前语言的课程显示名，并希望第一行提供名称识别题干。
- **方案：**固定结构为：`A1`＝当前语言课程显示名，`A2+`＝该行事物主媒体引用；`B1`＝名称与主媒体之间的双向题干，`B2+`＝事物名称/别名；`C1+`＝各属性的双向题干，`C2+`＝文本答案或属性媒体引用。
- **性质：**中性 A 列和 `A1` 课程名属于客户对 **ZNAWCA** 的明确要求；把名称题干顺移到 `B1` 是**主控已定**。
- **验收：**不同语言工作簿的 `A1` 可显示不同课程名；同一行的 A 列媒体和 B 列本地化名称稳定对应；`B1` 不再使用写死的 `Identify the object`。

### 2.3 媒体改为具体单元格映射

- **问题：**旧模型把全部媒体关联到整行事物。例如法国文件夹可同时含国旗、埃菲尔铁塔和国花，系统只知道它们都属于法国，无法判断各自代表哪个属性。
- **方案：**媒体引用语法统一应用于 A 列和所有普通属性单元格。引用的文件在共享 `media/` 中精确存在且格式受支持时，系统将其识别为媒体，不把文件名显示为文字。A 列媒体是整行事物的主表现，可代替 B 列名称作为提问其他属性时的事物线索；普通属性单元格中的媒体只表达该具体属性，并与 B 列名称形成可双向考察的关系。例如“法国 ↔ 国旗图片”“法国 ↔ 地标图片”。
- **边界：**只生成“名称 ↔ 对应单元格”题，不生成“国旗 ↔ 地标”“国旗 ↔ 国歌”等属性或媒体之间的题；内容媒体本身是题目或答案，不把它另作“答对文字题后播放的补充视频”。
- **性质：****主控已定**；这是对旧媒体使用方式的重构。
- **验收：**国旗题只使用国旗单元格引用的图片，地标题只使用地标单元格引用的图片，不再从整行媒体中随机混用。

### 2.4 一个单元格引用多个媒体

- **问题：**同一知识内容可能需要多种表现，例如成年鸟、幼鸟、飞行和停栖照片；它们不应互相成为错误选项。
- **方案：**允许一个单元格用半角正斜杠 `/` 列出多个同类型媒体文件，例如 `flag-front.png/flag-waving.jpg`。单元格只写共享媒体目录中的文件名，不写目录或路径，因此 `/` 只作为变体分隔符；文件名不得含路径分隔符，解析后必须校验真实路径仍位于课程媒体目录内。所有文件视为同一答案的媒体变体，每次出题随机选一个，并尽量避免短期重复。不同选项的图片可混用 JPG、PNG、WEBP 等格式，只要媒体类别均为图片。
- **边界：**A 列及每个普通属性列的非空单元格必须分别统一为文字、图片、音频或视频中的一种；图片列内可混用 JPG、PNG、WEBP 等格式。同一单元格只允许一种媒体类别及其多个变体，不得混合文字与媒体或多种媒体类别；需要不同类别时使用不同属性列。空单元格跳过。
- **性质：****主控已定**。
- **验收：**同一单元格的多张图片不会互为干扰项；同列或同格混合媒体类别时导入失败并精确指出列和单元格。

## 3. 出题规则

### 3.1 双向自然语言题干

- **问题：**单一短标题如 `Population` 无法同时自然表达“名称→属性”和“属性→名称”。
- **方案：**`B1` 以及所有可双向出题的属性标题统一写为 `正向题干 / 反向题干`；第一部分用于“名称→单元格”，第二部分用于“单元格→名称”。例如 B1 可写 `Which image shows this species? / What species is it?`，国旗列可写 `Which flag belongs to this country? / Which country does this flag belong to?`。
- **边界：**以首个 `/` 分隔两个方向；两部分均必填。缺少 `/` 或任一部分时拒绝导入，并提示文件、工作表和标题单元格位置。`/` 在标题中为保留语法字符。
- **性质：**斜杠双向题干为**客户明确提出**；首个 `/` 的解析规则、两部分强制必填及阻断导入为**主控已定**。
- **验收：**同一列正反向显示各自完整题干，不再显示写死的 `Identify the object` 或只有 `Population` 的短标签。

### 3.2 显式别名

- **问题：**系统不能自动判断 `China` 与 `PRC` 等同义词或别名。
- **方案：**先用半角分号 `;` 划分必须全部回答的组，再用半角正斜杠 `/` 划分组内任选别名。例如 `China/PRC; Asia` 要求回答 `Asia`，并接受 `China` 或 `PRC`。主控建议两者同时输入也判对，选择题按 Excel 原样显示已声明别名。
- **边界：**不自动推断同义词，不使用 AI。
- **性质：**客户明确提出 `/` 表示任选别名；分号优先于斜杠解析、同时输入多个已声明别名也判对、选择题原样显示全部别名为**主控已定**。
- **验收：**`China; Asia`、`PRC; Asia`、`China; PRC; Asia` 均判为完全正确；未声明的别名不自动接受。

### 3.3 歧义反向题与特殊列标记

- **问题：**“吃种子”可能对应多种鸟，不能生成只有一个正确答案的反向单选题。客户曾建议增加“仅作问题/仅作答案”的列标记。
- **方案：**继续检查反向关系是否唯一；不唯一时跳过该反向题。暂不增加反向多选题。**重新纳入特殊列角色标记作为补充机制**：作者可用稀有符号（`$` 或 `*`）在表头声明某列「仅作问题」或「仅作答案」；该标记不替代歧义反向题的跳过逻辑，只在作者显式声明时生效。
- **边界：**系统只对当前课程数据保证选项唯一，不推断现实世界中课程之外的知识；列标记仅约束出题方向，不改变数据本身。
- **性质：**跳过歧义题和不扩展反向多选为**客户已确认**；特殊列标记由「取消」翻转为「重新纳入（补充机制）」为**主控已定**。
- **验收：**多个对象共享同一属性值时不生成错误的反向单选题；正向题仍可正常生成；声明「仅作答案」的列不生成以该列为题干的反向题。

### 3.4 选择题干扰项

- **问题：**干扰项重复、与正确答案等价或属于同一单元格的媒体变体，会产生无效选择题。
- **方案：**先排除正确对象、等价文本、已声明别名及同单元格媒体变体，再抽取干扰项；优先生成 4 项，不足时使用 3 项。媒体选择题仍不足 3 个有效选项时，改为反向题“显示正确媒体→输入名称”，绝不要求学习者输入媒体文件名；普通文字选择题则降级为对应文字输入题。
- **性质：****现行需求基线**。
- **验收：**每道选择题只有一个答案组正确；不足有效选项时不拼凑错误题目。

## 4. 答案兼容与判定

### 4.1 分隔符、顺序与基础容错

- **问题：**学习者可能改变多部分答案顺序，或在答题时使用不同中英文标点。
- **方案：**Excel 统一使用半角分号 `;` 分隔必答组；答题端接受 `;`、`；`、`,`、`，`。多部分答案顺序无关；继续支持大小写不敏感、首尾空格忽略和连续空格压缩。
- **边界：**斜杠仅表示显式别名，不作为普通答案分隔符；反斜杠不具备语法含义。
- **性质：****客户已确认**。
- **验收：**同一组答案改变顺序或使用四种允许标点时，判定结果一致。

### 4.2 化学式下标

- **问题：**标准答案 `H₂O` 与键盘输入 `H2O` 当前可能被判为不同。
- **方案：**判题时仅将 Unicode 下标数字 `₀—₉` 与对应普通数字 `0—9` 归一后比较，其他化学式字符保持不变。不使用可能改变专业符号含义的通用 NFKC，也不把上标数字一概等同普通数字。
- **性质：****客户明确提出**。
- **验收：**`H₂O`/`H2O`、`CO₂`/`CO2` 可等价；`x²` 与 `x2` 不得误判为相同；字母、正负号和其他符号不同仍不得误判为相同。

### 4.3 完全正确口径统一

- **问题：**部分正确、漏答或多答可能在学习、测试和困难记录中得到不同结论。
- **方案：**只有全部必答组命中且没有额外错误答案时才是完全正确。Learning 中其他情况均显示差异并重做；Testing 中计 0 分；困难评价中视为本次未正确。
- **性质：****现行需求基线**。
- **验收：**同一作答在三个模块中的“完全正确/未完全正确”结论一致。

## 5. 范围、测试与困难内容

### 5.1 范围与筛选

- **问题：**“范围”曾被误解为需要直接选择 Excel 行或具体事物。
- **方案：**范围由两部分组成：使用 `#` 列筛选事物，再选择“本次全部关系”或指定抽取数量。同一筛选列多值为 OR，不同筛选列之间为 AND；不新增手选行区间功能。
- **性质：****现行需求基线**。
- **验收：**筛选结果、可用关系数和题量上限同步更新；筛选后答案完全相同的属性列自动跳过。

### 5.2 严格与宽松

- **问题：**严格/宽松容易与“困难内容优先”混淆。
- **方案：**严格/宽松只控制选择题干扰项来源：严格来自当前筛选范围，宽松可来自整门课程；题目对象始终来自筛选范围。困难内容优先只控制哪些事物更容易入选。
- **性质：****现行需求基线**。
- **验收：**切换严格/宽松不改变题目对象范围，只改变干扰项候选池。

### 5.3 测试题池

- **问题：**当前代码只允许已掌握关系进入测试，原需求没有该限制。
- **方案：**Testing 从当前筛选、题型和题量设置下的全部有效关系抽题，不以“已掌握”为前置条件；每条入选关系在本次测试中只出现一次。
- **性质：****现行需求基线**。
- **验收：**尚未掌握但位于用户所选范围内的关系可以进入测试；同一关系不会重复出现。

### 5.4 困难内容进入、优先与退出

- **问题：**当前代码按“事物＋属性/媒体”记录困难，使用固定 30%/40%配额，并按连续三次答对退出；均偏离当前需求基线，且“困难优先”开关没有真正控制抽题。
- **方案：**困难记录统一按“课程＋事物（Excel 行）”。一个已完成会话中，只要该事物出现任一错误或部分正确，即标记为困难并将恢复进度归零。开启困难优先时，困难事物固定权重 2、普通事物固定权重 1；关闭时全部权重相同。困难事物在后续两个“实际答到该事物，且该事物在该会话内没有任何错误”的已完成会话后移除；其他事物答错不影响它，未出现该事物的会话不计数。
- **边界：**删除 30%/40%固定配额和重复抽样算法；错误次数不继续累加权重。
- **性质：****现行需求基线**。
- **验收：**同一事物不同属性只产生一条困难记录；开关关闭时不优先；该事物连续两个有效无错会话后清除，该事物期间任一错误均归零，其他事物的错误不影响它。

### 5.5 学习模式错题回池顺序

- **问题：**学习模式首次题目顺序随机，但答错后题目按固定队列循环，学习者会反复看到同一顺序。
- **方案：**学习者答错或部分正确后，该题重新进入活动题池，并立即与剩余未掌握题一起重新打乱；若池中还有其他题，下一题不应固定为刚答错的同一题。
- **性质：**客户反馈，直接修正。
- **验收：**同一批题中连续答错多个题后，后续题目顺序不再按首次队列固定循环；保存并恢复未完成学习会话后，沿用保存时的队列，不额外重排。

## 6. 进度、布局与音频交互

### 6.1 进度统计

- **问题：**按“已经问了几题”统计会被错题重试放大，不能反映掌握情况。
- **方案：**一个“名称＋对应学习单元格”的有效关系计为一个知识关系：A-B 主媒体识别算一个，B 与每个有效、非空、非筛选属性单元格的对应关系各算一个。空单元格、缺失/损坏媒体及因无区分度被跳过的列不计入总数。正向/反向、输入/选择、主媒体替代名称作为事物线索以及多个媒体变体均不重复计数。Learning 会话开始时固定总数；达到活动池移除条件即计为已掌握；剩余＝总数－已掌握；重试不增加总数。Testing 显示总数、已完成和剩余。
- **性质：**改进目标为客户明确提出；上述计数口径为**主控已定**。
- **验收：**同一关系重试多次时总数不变；正反向题和不同题型不会重复占用进度。

### 6.2 媒体选项固定 2×2

- **问题：**四个图片或音频选项需要滚动，不利于同时比较。
- **方案：**四个媒体选项固定为 2×2；常规窗口内不滚动。窗口设置合理最小尺寸，三个选项按两行排列。
- **性质：**图片和音频 2×2 为客户明确提出；视频沿用相同布局为**主控已定**。
- **验收：**四个媒体选项在支持的最小窗口尺寸内同时可见且可操作；学习/测试会话页应撑满主窗口内容区，题卡不使用窄幅居中布局，避免在宽屏上留下大片外层绿色背景。

### 6.3 单元格文字朗读

- **问题：**文字问题和答案缺少与来源单元格稳定对应的发音；多语言共用 `C4.mp3` 会发生重名；双向题干同处一个标题单元格也需要区分方向。
- **方案：**朗读文件放在当前工作簿语言对应的 `speech/<language>/` 目录。普通单元格沿用坐标命名，如 `C4.mp3`；双向标题分别使用 `C1-F.mp3` 和 `C1-R.mp3`，B1 同理。文字题出现时，按界面显示顺序播放已有的文字片段音频；题目本身是图片、音频或视频时不自动朗读。问题行和文字答案按钮提供手动扬声器按钮。各语言工作簿保持相同行列布局；坐标变化时必须同步重命名朗读文件。
- **边界：**朗读音频与内容媒体是两套用途：前者朗读文字，后者本身就是题目或答案。没有朗读文件时静默跳过，不启用文字转语音。
- **性质：**朗读需求和坐标命名为客户明确提出；语言目录及 `F/R` 后缀为**主控已定**。
- **验收：**同一坐标在不同语言播放各自录音；正反向题干不会播放成同一段；点击扬声器不等于提交答案。

### 6.4 随机正误提示音与正确答案音频

- **问题：**单一正误提示音重复；提示音、自动朗读和正确答案音频可能重叠。
- **方案：**扫描课程根目录的 `correct NN.mp3` 和 `incorrect NN.mp3`（`NN=00—99`，编号可不连续）。提交答案后随机播放对应集合中的一个，并尽量避免连续重复；随后播放正确答案来源单元格的对应音频：文字答案播放坐标朗读音频，音频答案播放其内容音频，图片或视频答案没有独立正确答案音频时跳过。任何文件缺失或损坏均静默跳过，不阻断判题。
- **播放规则：**同一时间只运行一条音频链；进入下一题、手动重播、退出会话时停止上一条链。学习者手动点击另一个音频或视频控件时，正在播放的上一个媒体必须立即停止，不能重叠播放；自动朗读或反馈音频开始时，也应停止界面中正在手动播放的媒体。固定顺序为“正误提示音 → 正确答案朗读”。
- **性质：**随机文件命名与播放时机为**客户明确提出**；打断和降级规则为实施约束。
- **验收：**正确、错误分别从对应集合随机播放；任意两个音频/视频控件连续点击时前一个停止、后一个播放，音频不重叠；缺文件时答题流程正常。

### 6.5 界面语言修订

- **问题：**客户指出部分界面翻译有非预期或滑稽含义，但尚未提供完整清单。
- **方案：**待客户给出具体措辞后，只修改五种界面语言资源文件；课程内容仍完全取自工作簿，不自动翻译。
- **性质：**客户明确提出，具体文案待客户提供。
- **验收：**所有固定文案来自语言资源；阿拉伯语保持 RTL；课程数据不被界面语言改变。

### 6.6 桌面图标质量

- **问题：**当前桌面图标观感粗糙，图形分辨率不足，绿色背景与产品界面风格不匹配。
- **方案：**替换为透明背景的高分辨率图标，采用与应用界面一致的深色、金色品牌风格，并保留多尺寸 ICO 以适配 Windows 桌面、开始菜单和安装包显示。
- **性质：**主控反馈，直接修正。
- **验收：**`assets/icon.ico` 至少包含 16、24、32、48、64、128、256 像素尺寸；图标不再使用绿色背景；桌面缩略图下仍能清楚识别 Znawca 品牌。

## 7. 工程约束与实施顺序

### 7.1 新旧课程兼容

- **问题：**单元格媒体和多语言工作簿会改变现有 V1 课程格式。
- **方案：**使用可明确识别的格式版本区分：V1 继续按“名称目录→整行媒体”只读兼容；V2 使用本方案的单元格媒体和多语言结构。格式版本的存放位置随 V2 模板一并确定，不允许靠猜测自动切换。程序不得静默改变旧格式含义，也不得修改用户源 Excel。
- **性质：**实施约束。

### 7.2 导入错误

- **问题：**新结构会增加题干、媒体引用、语言和元数据错误。
- **方案：**所有错误必须给出文件路径、工作表、具体单元格、原因和修复示例。单元格内容具有受支持的媒体扩展名时即按媒体引用校验：文件缺失、损坏或类别不符时记录可定位警告并跳过该媒体/关系，不阻断同课程其他有效内容，也绝不能退回成可作答的文件名文字；只有课程因此不再含任何有效学习关系时才阻断导入。可选朗读和正误提示音缺失时静默跳过或给出非阻断警告。
- **性质：**客户认可的现有体验＋实施约束。

### 7.3 启动性能与按需加载

- **问题：**保存课程库后，程序启动会重新完整扫描库下每一门课程，课程和媒体越多启动越慢，也会造成不必要的磁盘读取。
- **方案：**启动和“刷新课程库”只做轻量目录发现：列出候选课程目录、Excel 文件和语言后缀，不读取工作簿正文，不扫描图片、音频、视频。只有学习者本次点击打开某门课或恢复该课未完成学习时，才完整加载对应课程并校验该课程媒体；后台只允许从当前已选择课程库内加载课程，课程与媒体路径均按真实路径确认不得通过链接跳出允许范围。媒体格式校验只读取文件头所需字节，不再为判断格式读取完整媒体文件。
- **性质：**客户明确提出，直接修正。
- **验收：**有大量课程材料时，启动不再遍历加载全部课程内容；打开课程库只出现课程入口；点击某门课后只加载该课程；重复点击同一课程不会触发重复加载；媒体签名校验不读取整个媒体文件。
