# 项目文件组织方案（摘要）

## 目标

- 根目录只保留入口文档、源码目录和项目配置。
- 建立固定阅读路径，避免 Agent 重复扫描历史资料和大文件。
- 分离当前需求、方案、验收、历史资料、工具、样例和交付物。

## 阅读路径

`AGENTS.md` → `每轮必读.md` → `优化方案/README.md` → `优化方案/阶段摘要.md` → 当前议题文件。

原始需求和证据仅在需要核对时通过 `docs/README.md` 读取。

## 默认不读取

`.git/`、`.workbuddy/`、`node_modules/`、`dist/`、`release*/`、`artifacts/`、`samples/`、`docs/archive/`。

## 权威规则

- 每类信息只保留一个当前版本。
- 旧版本归档，不与当前版本并列。
- 原始反馈只作证据，不直接作为实施指令。
- 当前未提交代码修改必须保留。

## 状态

目录整理已由 WorkBuddy 执行；详细记录保留在 `docs/plans/PROJECT_ORGANIZATION_PLAN.md` 和 `docs/plans/REORGANIZATION_REPORT.md`。
